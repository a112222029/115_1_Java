# 第二週 AI 使用紀錄

| 欄位 | 學生填寫 |
|---|---|
| 使用工具 | GitHub Copilot Chat（VS Code）、ChatGPT |
| 使用目的與提問摘要 | 我使用 AI 協助檢查 `RoverMission.java` 的探索條件，詢問將 `energy >= 6` 改成 `energy > 6` 是否正確，以及能源剛好等於 6 時該如何驗證。 |
| AI 建議與本人處理 | Copilot 說明探索需要至少 6 格能源，所以條件必須包含等於 6。我先自行測試老師提供的錯誤條件 `energy > 6`，確認會錯誤拒絕探索，再改回 `energy >= 6`，並將測試用的初始能源恢復為 20。 |
| 實際驗證結果 | 初始能源 6、輸入 1：正確條件得到能源 0、樣本 2、行動 1，顯示 `EXHAUSTED`。錯誤條件下輸入 1、0，則出現 `NOT_ENOUGH_ENERGY`，最後得到能源 6、樣本 0、行動 0，顯示 `RETURNED`。修正後測試連續五次輸入 2，結果為能源 10、樣本 5、行動 5，顯示 `SUCCESS`；輸入 3、9、0，結果為能源 20、樣本 0、行動 0，顯示 `RETURNED`。實際結果與預期一致。 |

## AI 使用心得

這次我發現程式的判斷條件即使只差一個等號，也可能造成不同結果。透過 AI 的說明，我理解了邊界值的問題，再自行修改程式並執行測試，確認修正後的程式符合要求。
